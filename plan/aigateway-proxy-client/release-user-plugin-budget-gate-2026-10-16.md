## 生效规则

- 下载角色权限与个人预算配置是两个独立前提；Owner 也不能绕过个人预算门槛。
- 使用平台既有 UTC 月度周期和 `effective_user_id`，查询本月个人预算配置，
  支持 Token、USD；不扫描消费流水，也不以剩余额度或 audit/block 模式判断是否已开通。
- 未配置个人预算时，不显示用户版安装步骤、凭据确认框和下载按钮，显示
  「暂未开通预算，请联系部门管理员。」；不再附带误导性的「当前平台暂未启用用户版」。
- 下载选项返回明确的 `budget_configured` 状态；未配置时不返回默认订阅。
  ZIP 接口在生成授权凭据之前重新校验，直接请求返回 HTTP 403。
- 组织、部门、应用共享预算不能替代本人本月预算。仅存在过期或未来预算也不满足条件。
- 订阅版行为、现有插件运行鉴权和默认订阅选择不变。本次没有主动撤销用户既有插件授权。
- 用户版仍为 0.5.0，订阅版仍为 0.1.4；本次门槛在平台下载环节生效，不要求已有用户重装。
