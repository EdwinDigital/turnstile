# AIGateway-Proxy 客户端需求分析

日期：2026-10-11。范围：Turnstile 用户菜单、下载页面和 magpie 供应商插件；不修改 magpie 源码，不发布到公共 npm。

## 用户流程

1. 登录用户在头像菜单选择「下载客户端」，进入独立页面；两个数据源下均可访问，下载数据始终来自平台 APIM。
2. 选择有权限的应用订阅、对应平台网关及主/备用订阅密钥；页面展示网关地址、模型及下载包含密钥的警告，不显示密钥。
3. 下载 ZIP，内含完整供应商插件、当前订阅配置和安装说明。解压后在 magpie「插件」页添加本地文件夹，点击供应商登录中的「导入下载配置」。
4. 供应商及订阅获授权的已发布对话模型出现在 magpie 中，可供其他 Agent 通过 magpie 网关使用。

## 当前核心验证边界（用户 2026-10-11 更新）

- 用户明确要求先不考虑权限控制，先实现核心功能验证。第一阶段暂不开发 Member 应用行归属、部门/团队委派或新的权限菜单；API 沿用现有 OwnerSession，不开放匿名或普通用户密钥导出。
- 保留现有系统订阅排除、启用状态、网关一致性、模型策略和跨站保护。这些是配置正确性及既有系统约束，不修改既有授权/预算/网关策略。
- 下载导出已有订阅密钥，不创建或轮换密钥。响应 no-store，私密配置不写 Git、URL 或日志。网关只接受当前平台 APIM 的配置，不接受浏览器任意 URL。
- 普通用户下载和精细权限控制延后，核心交付不宣称已经支持。菜单可见，非 Owner 页面明确提示当前阶段限制。

## 协议和范围

- 使用 OpenCode v1 兼容供应商插件，不用无 fetch 能力的网关中间件。依照官方文档及本地 host.js 核对入口和钩子。
- 根据生效网关发布的 api_format，为模型选择 Responses、Messages 或 Chat Completions；使用平台模型别名，不用 Foundry 上游部署 ID。
- 首期只导出已启用、已发布、应用允许访问的对话模型；图像生成不伪装成对话模型。动态发现仅保留下载快照与线上 /v1/models 的交集；新增授权模型需重新下载。
- 一个下载包对应一个应用订阅和网关，稳定且隔离的供应商 ID 允许多个订阅并存；不覆写已有供应商登录。
- 不修改数据库 schema、APIM 策略、预算控制、模型授权或平台基础设施。

## 验收

- Owner 用户菜单入口、桌面/手机布局、表单联动、空列表、错误/重试、重复提交及会话过期。
- API 401、越权 404、系统/失效订阅、错配网关、跨站 POST、无已发布模型、密钥读取失败及敏感响应缓存。
- ZIP 内容完整、无代码/路径注入、配置与所选订阅一致；插件不向其他地址转发密钥、不跟随重定向，取消和流式响应保持原样。
- 隔离 HOME 导入真实 magpie；使用指定 cc-switch 订阅执行真实模型连通和流式调用。保留用户原有登录、插件和 Agent 配置。
- 发布前保留当前生产包，构建并验证完整 API 包；上线后核对真实页面、授权下载、magpie 导入和调用。测试与发布证据写 implementation.md，私密配置和截图保留 Git 外。
