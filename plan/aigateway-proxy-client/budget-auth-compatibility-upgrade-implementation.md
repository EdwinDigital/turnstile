## 金融切换与回退门槛

应用包验证成功不等于 USD 已激活。执行安装前仍须完成设计中的 Observer、所有可达修订共享
fence、精确 ETag、停流排空、fresh readback、价格/计数证据、期初只初始化一次以及真实 Token/USD
结算验收。不能用离线生成成功或页面 capabilities 代替这些证据。

若尚未启用金融协议，回退使用已验证的旧运行包及完整设置，保留当前数据库和账本。
若金融协议已经产生新消费，必须先 paused、排空和结算、对齐 SQL/S 摘要、隔离 USD 身份，
再投影最新旧 C/Q 并恢复旧准入；不得恢复旧余额覆盖新消费，不删除 S/A/D 或历史原始数据。
未满足这些条件时应保持受控停止状态，而不是盲目切回旧策略。

线上真实调用仅通过正常用户版授权和有效 `turnstile-dashboard` 订阅进行，不绕过预算、模型
权限或 APIM。GPT-6.1-sol 一次返回 200，输入 12、输出 5，共 17 Token；正式用量记录确认
真实 Edwin 身份、原生会话标识、轮次、价格和个人预算增量，费用为 USD 0.000123。
随后在修正 managed endpoint 登记路径后，Grok-4.7 正常用户请求返回 200，输入 6、输出 26，
共 32 Token，正式记录费用为 USD 0.000168。两次真实调用共计 49 Token、USD 0.000291，
个人用量从 3,569,747 增加到 3,569,796；均为显式独立调用，没有自动重试模型请求。
测试用的未登记 Agent 名称被现有目录规则归为 `unattributed`，没有将任意客户端标签伪造成
已登记的组织 Agent。会话标识和个人归属验证成功，不将其误报为已验证 Agent 归属。

登记原网关元数据时保持唯一 profile、名称、凭据和默认订阅不变。联调发现，ARM 返回的
service origin 不能替代调用所需的完整 API URL：managed deployment endpoint 必须沿用
既有 `/turnstile/llm` 路径，否则平台默认凭据匹配会正确 fail-closed，用户版下载返回 409。
该登记值已纠正，并确认用户版下载选项恢复可用。后续初始化工具必须校验完整 API 路径，
不能仅比较 host 或手工拼一个 ARM origin；普通调用不得为适配错误 URL 放宽凭据目标校验。
