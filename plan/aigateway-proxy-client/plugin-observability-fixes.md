# 插件可观测性修复（0.4.1 用户版 / 0.1.2 订阅版）

## 问题、方案与边界

| 问题 | 处理 |
| --- | --- |
| 模型完整 ID 暴露用户/订阅 UUID | 新下载包用用户名或订阅名生成命名空间，短摘要区分同名来源；非 ASCII 技术名称编码，显示名不编码。旧安装显式替换。 |
| 只有 Token，没有金额 | 复用 repository.model_prices()，导出平台计费实际使用的四类单价；用户版下载和刷新目录均带 cost。订阅版带价格快照，有效 discovery cost 可以更新已导入模型。 |
| native 插件适配漏掉缓存价格 | 用现有原生 model price CLI 导入本供应商的完整单价，含与平台缓存写入相同的 1h 价格，避免宿主自行推断不同 TTL 单价。 |
| 手动价格或其他供应商被覆盖 | 只管理本 provider/model 的价格；不同于本插件上次导入值的手动设置优先，provider/* 与 */model 手动设置也优先。原生命令写配置，插件不直接改 settings.json。 |
| 个人 audit 窗口没有曲线 | 保留 aside=true。新增“查看额度趋势”，打开插件私有的独立 HTML 曲线，原生卡片不嵌入曲线。 |
| WorkBuddy 未提供会话、没有 Agent 图标 | 不伪造客户端会话、账号关联或修改 WorkBuddy 配置；继续作为已确认的宿主/客户端边界记录，不宣称修复。 |

本修复不修改 magpie 源码、APIM 策略、默认订阅、模型权限、预算阻断行为或数据库原始记录。
图片仍通过已有 MCP/图片助手调用；价格命令子进程不启动图片助手，不重建 OAuth 登录。

## 价格同步

- 单位与平台相同：USD / 百万 Token。缺失价格保持 null，显式零保持零。
- 缓存缺省处理直接复用平台 model_prices()，不重复推断折扣或另查公价。
- 价格状态、完整导出与已管理值保存在本插件命名空间的私有文件内，权限 0600。
- 子命令用参数数组执行，限制为本 provider/model；不使用 shell，不传登录凭据。
- AIGATEWAY_PRICING_WORKER 防止子进程递归同步，以及账号导入、改名、图片助手副作用。
- 每轮最多八秒；未完成的项后续刷新模型重试。没有 CLI/不支持的数据目录不强改宿主文件。
- 若完整缓存价没有成功导入，不能向 native 报出缓存免费；保留未知价格状态。
- 现有模型价格设置可能按当前价格重算本机历史估算，不是改平台原始账单。

## 独立个人额度趋势

- 使用已有 auth.usage 的个人快照，不增加后台 API 定时器或数据库查询。
- 只记录个人窗口，按平台 as_of 去重，五分钟内保留首点与最新点，最多保留 90 天/10000 点。
- 不填补安装之前的数据，不从共享应用或其他账号搬入历史，不将曲线当作实时推送。
- 快照和 HTML 只写本插件私有目录；不写 magpie 全局 quota-history.json。
- 读数仍有平台 60 秒缓存；独立页面显示数据时间、浏览器时区及非阻断状态。
- 查看入口复用当前授权；必要的过期续期复用现有逻辑，不发起浏览器重新认证或切换订阅。
- HTML 不含 OAuth/API Key 或用户 UUID，显示数据转义；损坏或外来用户历史保留，不静默覆盖。
- file: 入口面向本机桌面版。原生卡片 mini-chart、远程网页文件打开不在此兼容方案承诺内。
